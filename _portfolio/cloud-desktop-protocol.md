## Overview

Cloud desktop protocol development in the cloud desktop team at Huawei. Responsible for designing and implementing network protocols that enable efficient display transmission, low-latency user interactions, and reliable connection management between clients and virtual desktops.

## Key Contributions

- Protocol design and implementation for display frame encoding and transmission
- Network connection management including session establishment, keep-alive, and reconnection
- Latency optimization through adaptive encoding and network condition awareness
- Cross-platform client compatibility (Windows, Linux, macOS)
